   - **Authorship caveat (must appear in README):** written by the AI coding assistant that also builds the system, not by an independent person, because the team is one human with three hours. 16. **Overfitting controls and their limits.** (a) Test split frozen by hash; `eval/run_eval.py` refuses `--split test|all` without `--final`, refuses if the test-set hash changed, logs every test run to `eval/results/test_run_log.txt`, and records the git commit. (b) Rule-based, so no model weights to overfit, but rules ARE corpus-specific wording rules. (c) Two generalisation sets of ad-hoc queries with different phrasing, scored on FIRST pass before any fix: set A 21/24 (87.5%), set B 13/15 (86.7%). Failures were fixed afterwards as general changes (no special cases); the later 24/24 and 15/15 are contaminated and must not be quoted as generalisation. (d) Extraction audit rounds used fresh seeds; round D untouched. **Limits to disclose:** I wrote the test set and know its content, and I read the documents behind it, so the test split is not blind; refusal rules were written from general principles but by someone who had seen the test wording, so the refusal category is likely optimistic. Dev split is 10 questions only, so nothing tuned on it is reliable. `T_LOW = 8.0` (BM25 floor) was set by inspecting score ranges (relevant 15-21, irrelevant 4-9) and checked on dev + ad-hoc only; short entity queries bypass it when a rare corpus term matches (`rare_query_tokens`).
17. **Refusal logic** is rule-based and ordered: off-topic -> airworthiness/safety judgement -> pre-2001 -> question about an external document -> final-rule question -> unknown docket/AD -> not Part 39 -> ambiguous -> unknown entity word -> contradictory make/model -> low retrieval evidence -> value asked for but number absent from text.
18. **No generated text.** Answers are verbatim spans (re-verified against the stored source before returning; `dropped_quotes` is reported) plus fixed template labels. The Anthropic key is not used anywhere in the answer path.
